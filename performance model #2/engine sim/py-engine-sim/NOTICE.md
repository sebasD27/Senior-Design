# Attribution and scope

This project is an independent Python implementation of reduced-order
turbojet and nozzle calculations. It is inspired by the educational NASA Glenn
EngineSim and Nozzle simulations and by the publicly available Java source
code for the NASA EngineSim University application:

- https://www.grc.nasa.gov/www/k-12/BGP/ngnsim.html
- https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/nozzle/
- https://github.com/ggranum/nasa-engine-sim-ua

NASA's original EngineSim source carries a public-domain notice. This project
does not claim to be NASA software, does not reproduce the original GUI, and
does not provide validated performance data for any commercial engine.
